# Secure SKY130 offline configuration

`configure-sky130` accepts only `org.biasweave.sizing-decision` version 1. The
decision is limited to 1 MiB and must match caller-supplied decision, benchmark,
comparison, topology, and topology-signature trust anchors. It rejects duplicate
JSON keys, unknown or missing fields, non-finite values, re-signed but untrusted
content, unsupported selection provenance, and sizing values outside the bounds.

The supported PDK is Ciel SKY130A revision
`1689ac3f2dc763876eaf967227c7dfe831b031ae`. Official Ciel release asset hashes,
the installed `nodeinfo.json` hash, and hashes for all four selected model files
are pinned in code. Configuration is offline and fails closed on any mismatch.
The generated provenance uses logical release identifiers only; absolute host
paths are excluded so identical inputs on different machines remain identical.

The result contains the canonical decision, logical provenance, a no-`.control`
deck, four copied model files, and a strict manifest. All are declared inputs,
so SimCairn fingerprints them. The product sweep has 27 points:

- TT, SS, FF;
- 1.62, 1.80, 1.98 V;
- -40, 27, 125 C.

The reliable batch measures are average output voltage, output peak-to-peak,
100 kHz voltage gain, average supply current, and average power. Raw transient
measures are forwarded through parameter measures so ngspice emits exact
`name = number` lines accepted by the strict adapter. Bandwidth is intentionally
not included: ngspice 42 cannot reliably chain the required top-level AC
measure without using the deliberately excluded control language.

Generation is atomic and refuses existing destinations. Model sources and the
destination are never passed through a shell. See the example README for the
materialization mapping and command.
